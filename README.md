# Photo Portal Frontend

A web frontend for a customer photo portal.

This repository is a snapshot of my primary contribution to a full-stack application developed for [Cutthroat Visuals](https://www.cutthroatvisuals.com/) from April-May 2026. The frontend itself is fully generated on the client side, but it is effectively unusable without a backend to respond to its API calls, which is not included here.

## Install and preview

1. [Install Node.js](https://nodejs.org/en/download) (the latest LTS version.)
2. [Install the Angular CLI](https://angular.dev/tools/cli/setup-local#install-the-angular-cli).
3. Run `npm i` in this directory to install dependencies.
4. Run `ng serve` to start a dev server.
5. Open `http://localhost:4200/` in a browser.

The passcode page should be viewable, but the lack of a backend will cause the passcode API call to fail.

## Dependencies
- [TypeScript](https://www.typescriptlang.org/)
- [Angular](https://angular.dev/) (front-end web framework)
- [PrimeNG](https://primeng.org/) (UI library)
- Assets from the [Cutthroat Visuals](https://www.cutthroatvisuals.com/) webpage
